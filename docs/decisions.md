# KODA 산학과제 의사결정 기록

방문 논의에서 확인한 방향과 이후 결정할 항목을 구분해 기록한다. 아래 기록은 2026년 10월 16일 방문 자료를 정리한 것으로, 별도 승인 근거가 없는 기능은 확정 결정으로 취급하지 않는다.

출처는 [대시보드 요구사항의 S1·S2](dashboard.md#범위와-근거)를 따른다.

## 새 결정의 기록 형식

새 결정에는 ID, 결정일, 상태(제안·결정·보류·대체), 관련 요구사항 ID, 결정 내용, 근거, 검토한 선택지와 영향을 적는다. 승인 주체나 담당은 확인된 경우에만 기록한다. 기존 결정을 변경하면 이전 기록을 지우지 않고 대체 관계를 연결한다.

## 제안 기록

아래는 개발용 앱을 만들며 정리한 **제안**이다. KODA가 승인한 결정이 아니며, 승인 주체가 확인되면 상태를 바꾸고 이전 기록은 남긴다. 출처 S3(KODA 고객 대시보드 이용가이드)은 쪽 번호만 인용한다([인용 방식](../app/docs/traceability.md#출처)). 설계 가정 ID(A-xx)는 [app/docs/assumptions.md](../app/docs/assumptions.md).
