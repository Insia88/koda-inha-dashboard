# KODA × 인하대학교 산학협력 대시보드

디지털자산에 익숙하지 않은 법인 고객이 자산 현황과 업무 상태를 이해하고 안전하게 이용하도록, 대시보드의 정보 구조·용어·요청 및 승인 흐름을 개선하는 산학과제다.

- [10월 16일 방문 미팅록](docs/meetings/2026-10-16.md): 논의 내용, 일정, 후속 액션
- [의사결정 기록](docs/decisions.md): 확인된 방향과 후속 결정 항목

Notion 페이지는 해당 워크스페이스의 접근 권한을 따른다. Drive의 링크 편집 권한과 GitHub의 공개 열람은 별도다. GitHub에서 직접 커밋하려면 공동 작업자 권한이 필요하며, 권한이 없는 참여자는 Fork 후 Pull Request로 수정안을 제안한다.

## 파일을 관리하는 기준

Markdown 문서의 최신본은 이 저장소에서 관리한다. 에셋과 PPT·PDF·이미지 등 발표 파일은 Drive에 두고 문서에서 링크한다. Drive에 내보낸 Markdown은 스냅샷이며 별도로 동시에 수정하지 않는다. 팀이 확정한 결론은 Notion 회의록과 의사결정 기록에 반영한다.

현재 요구사항은 방문 논의에서 출발한 초안이다. 개인 제안, 검증 가설과 확정 결정을 구분하며 구현 범위·담당·기한은 합의 근거가 생기면 기록한다. 10월 28일(수) 중간발표를 준비하며, 10월 22일(목) 팀 회의의 시간·장소는 별도 확정한다.

프로토타입 검증에는 가상 법인·모의 거래 데이터를 쓴다. 실제 고객 정보·지갑주소·개인키·인증정보·보안 운영 상세는 저장하지 않는다. 로고와 외부 에셋의 권리는 각 권리자에게 있으며 [에셋 사용 안내](https://drive.google.com/file/d/1FD1oo20rx0TdFx4aRI52w-Y-M476B9VB/view)를 따른다.
