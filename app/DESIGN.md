# DESIGN.md — KODA 법인 대시보드

대상: 디지털 자산에 익숙하지 않은 법인의 자산 담당자·승인자·감사 담당자. 화면마다 "지금 상태 → 내가 할 일 → 근거"가 먼저 읽혀야 한다. 구현 토큰은 `src/styles.css`의 `:root`와 같다.

## 색
| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| Ink | `#10201B` | 본문 글자, 주소 대조 띠의 강조 묶음, 다음 할 일 패널 |
| Paper / Surface | `#F4F6F5` / `#FFFFFF` | 배경 / 카드·표 |
| Line | `#DBE2DF` (강한 선 `#B9C4C0`) | 구분선, 입력 테두리 |
| KODA Green | `#00D998` | 공식 로고 색. 선택 표시 막대·다음 할 일 테두리 등 **면/선에만**. 흰 바탕 글자색 금지(대비 부족) |
| Action | `#00704F` (hover `#005A40`) | 주 버튼·링크. 흰 글자와 대비 AA 이상 |
| 상태 | info `#1F4FBF` · warning `#8A5000` · danger `#B42318` · success `#116A45` · neutral `#4B5853` | 배지·안내. 각 색은 연한 배경(`*-soft`) 위 글자로 사용 |

- 로고는 `public/koda-logo.svg`(공식 웹 로고 원본 경로) 그대로 흰 바탕에 표시한다. 색·비율을 바꾸지 않으며, 파생 파비콘을 만들지 않는다.
- 차트 팔레트는 `AllocationBar`의 6색(짙은 녹·청록·보라·황토·회녹·자주). 색만으로 구분하지 않도록 항상 범례에 자산 코드와 %를 함께 쓴다.

## 서체
- 본문: Pretendard → 맑은 고딕 → Apple SD Gothic Neo (시스템 폰트, 외부 다운로드 없음). 15px / 행간 1.55. `word-break: keep-all`.
- 제목: 같은 서체 700. h1 24px, h2 17px.
- 숫자: `font-variant-numeric: tabular-nums`, 오른쪽 정렬. 주소·참조번호: Cascadia Mono → D2Coding → Consolas.

## 간격·모양
4px 배수(4·8·12·16·24·32·48). 카드 반경 8px, 입력 6px. 최소 클릭 영역 40px(작은 버튼 32px).

## 숫자·단위·시각
- 수량은 자산 최소 단위까지 정확한 문자열로 표시하고 단위(`BTC`)를 붙인다. 표시 포맷(`1,234.5`)과 저장값(최소 단위 정수 문자열)은 분리한다.
- 원화 평가액은 "약 55.11억 원" 보조 표기 + 정확한 원 단위를 함께 둔다. 평가액 옆에는 **시세 기준 시각(KST)·출처·데이터 상태 배지**(모의 데이터 / 시세 지연 / 시세 없음)를 항상 둔다.
- 날짜·시각은 `YYYY-MM-DD HH:mm` (KST).

## 상태 표현
- 요청: 작성 중(neutral) → 검토 중(info) → 승인 대기(warning) → 처리 중(info) → 처리 완료(success) / 반려·처리 실패(danger) / 취소(neutral). 문구와 설명은 `shared/terms.ts` 단일 출처.
- 4단계 진행 레일(작성·검토·승인 대기·처리 결과)을 목록·홈·상세에서 같은 모양으로 쓴다. 현재 단계는 `aria-current="step"`.
- 상세 화면 상단의 **다음 할 일** 패널(Ink 바탕 + Green 테두리)은 역할별 문장 하나만 보여 준다.

## 주소 대조 띠 (고유 요소)
주소를 4자 묶음으로 나누고 첫·마지막 묶음을 Ink 바탕으로 강조한다. 목록에서는 첫·끝 묶음만(…로 연결), 상세·확인 화면에서는 전체를 보여 준다. 메모/태그는 주황 배지로 주소 옆에 붙인다. 이 표시는 육안 대조를 돕는 장치일 뿐 안전성 보증 문구를 붙이지 않는다.

## 표
- 머리글 13px 굵게, 숫자 열 오른쪽 정렬, 행 구분선 1px, 자산 그룹 시작 행은 2px.
- 긴 텍스트는 `cell-wrap`(최대 360px 줄바꿈), 좁은 화면에서는 표 영역 가로 스크롤. 홈 자산표는 560px 이하에서 카드형으로 쌓는다.
- 목록 탐색은 탭마다 다르게: 활동 내역·감사 기록은 페이지(크기 선택), 요청은 페이지 10건 기본, 주소록은 페이지 없이 검색·필터, 인사이트는 "더 보기". 필터·페이지는 URL에 저장해 새로고침·상세 복귀 후 유지하고, 필터를 바꾸면 1페이지로 돌아간다.

## 폼
- 단계별 `fieldset`(번호 원 + 질문형 legend). 앞 단계가 끝나야 다음 단계가 활성화된다.
- 레이블은 항상 보이게, 도움말은 레이블 아래, 오류는 입력 아래 빨간 글자 + `role="alert"`. 서버 오류는 필드 오류와 상단 안내(원인 + 복구 행동) 두 곳에 표시.
- 되돌릴 수 없는 행동 전에는 원본을 보고 끝자리를 다시 입력(붙여넣기 차단)하고 확인 체크를 받는다.

## 고지·환경 표시
- 상단 고정 띠: "개발 환경 · 개발용 로그인 · 모의 데이터 · 모의 커스터디". 운영 연동 전에는 제거하지 않는다.
- 중요 고지(주소록 '사용 가능'의 의미, 네트워크 선택 위험, 인사이트 이용 고지)는 본문 크기 글자로, 접거나 회색으로 약화하지 않는다.

## 접근성 기본값
건너뛰기 링크, 화면 전환 시 h1로 포커스 이동(첫 화면 제외), 보이는 포커스 링(3px 파랑), 아이콘 버튼 `aria-label`, 상태 변경 `aria-live`, `prefers-reduced-motion` 존중. axe 자동 검사(WCAG 2.1 A/AA 규칙)를 E2E에 포함한다.
