# 실험 기능: 보유 자산 관련 리서치 보기

- 상태: **개인 제안 기반 실험, 기본 꺼짐**. KODA가 합의·승인한 기능이 아니다(`../../docs/decisions.md` OPEN-005).
- 근거: 방문노트의 개인 제안 — 고객사 특성·지갑 구성·보유 자산을 고려한 맞춤 리서치(S2). 제안 이미지(market-insight-proposal-1/2)는 승인 디자인이 아니므로 화면에 반영하지 않았다.
- 켜는 법: `config/insight-policy.json`의 `experiments.holdingRelatedFilter`를 `true`. 마켓 인사이트 화면에 "보유 자산 관련 (실험)" 칩이 생긴다. 꺼져 있으면 API가 404 `EXPERIMENT_DISABLED`.
- 데이터 범위: 로그인한 조직의 **보유 자산 코드 목록만** 서버 안에서 자료의 자산 태그(운영자가 지정)와 비교한다. 고객사 업종·규모·거래 내역·지갑 주소는 쓰지 않으며 외부 기관으로 보내지 않는다.
- 하지 않은 것: 추천 순위·개인화 문구·고객사 예시(공유 화면의 "고객사 A", 스테이블코인 비중 등)는 구현하지 않았다. 효과는 측정하지 않았다.
- 채택 전 필요한 결정: 사용자 필요 확인, 허용 데이터 범위, 자료 태깅 운영 주체, 투자 권유로 오인될 위험에 대한 고지 문구.
