# 설계 가정 (변경 가능)

실제 KODA 상태 체계·권한·정책 자료가 없는 부분은 아래 가정으로 구현했다. 근거 자료가 확보되면 해당 항목과 코드 위치를 바꾼다. 요구사항 출처는 `../../docs/dashboard.md`, 결정 대기 항목은 `../../docs/decisions.md`의 OPEN-xxx, 제안은 DEC-xxx.

**모든 행은 설계 가정이다. KODA가 확인한 정책·한도·규제 해석이 아니다.** 숫자(1억 원, 30분, 5분, 6자리, 8자리, 4자·8자, 5자, 200건, 120분 등)는 모두 이 저장소가 검증을 위해 정한 값이다. 이용가이드(S3) 쪽 번호는 `traceability.md`의 출처 표를 따른다.
