# 탭별 설계 기록 (DASH-005)

데이터량은 검증용 가정이다(모의 거래 137건·주소 12건). 실제 사용량이 아니다.

| 탭·주 과업 | 정보 위계 | 목록 탐색과 이유 | 상태와 행동 | 예외 상황 |
| --- | --- | --- | --- | --- |
| 홈 — 모든 역할: 지금 상태·할 일 확인 | 처리할 일 → 보유 자산(평가액·기준 시각) → 진행 요청 → 최근 활동 | 목록 없음, 각 영역 상위 5~6건 + "전체 보기" | 역할별 할 일 카드, 15초마다 갱신 | 할 일 없음·자산 없음·진행 요청 없음 안내 |
| 잔고 — 자산 담당자: 사용 가능 수량 확인 | 총 평가액·기준 → 자산×지갑 보유/예약/사용 가능 | 자산 수가 적어 페이지 없음 | 예약 수량 설명 | 자산 없음 |
| 자산 활동 내역 — 감사·담당자: 특정 거래 찾기 | 일시·종류·상대방·수량 → 네트워크·상태·참조 | 많은 기록 → 서버 페이지(10/25/50/100), 종류·자산·상태·기간·검색, 최신/오래된 순. 필터 변경 시 1페이지 | 출금은 요청 상세로 연결 | 조건 결과 없음(초기화 버튼), 범위 밖 페이지(첫 페이지로) |
| 결재 및 요청 — 승인자: 내 차례 / 요청자: 내 요청 | 번호·상태·목적 → 수량 → 요청자→받는 곳 → 4단계 레일 | 보기 탭(조직 전체/내가 승인할/내가 작성한) + 상태 칩(건수 포함) + 검색, 페이지 10/25/50 | 상세에서 역할별 행동만 노출, 서버에서 다시 검사 | 승인할 요청 없음, 요청 없음 |
| 주소록 — 담당자: 받는 곳 찾기·등록 / 승인자: 확인 | 이름·받는 곳 → 자산/네트워크 → 주소 앞·뒤 → 상태 | 수십 개 규모 가정 → 페이지 없이 전체 + 검색·상태·자산·네트워크 필터, "확인 필요 먼저" 기본 정렬 | 확인 대기 행에 "내 확인 필요" | 결과 없음, 첫 주소 등록 유도, 긴 이름 줄바꿈 |
| 스테이킹 — 조회 | 자산·검증인·수량·30일 보상·상태 | 소량, 페이지 없음 | 조회 전용(가정 A-09) | 스테이킹 없음(모의법인 B) |
| 지갑 관리 — 입금 주소 안내 | 지갑·네트워크·받을 수 있는 자산 → 입금 주소(+태그) → 잔고 | 카드 그리드 | 태그 필요 지갑 경고 | 지갑 없음 |
| 토큰 목록 — 지원 자산 확인 | 자산 → 네트워크 → 자릿수·메모·주소 형식 | 소량 표 | — | — |
| 조직 관리 — 관리자: 역할 변경 | 구성원·역할 → 승인 정책(가정 표시) | 소량 표 | 역할 변경(버전 충돌 검사, 본인 관리자 해제·마지막 관리자 해제 금지) | — |
| 감사 기록 — 감사 담당자 | 무결성 상태 → 순번·일시·수행자·행동·내용 | 페이지 25/50/100, 행동·수행자·기간·검색, CSV(필터 적용) | 내보내기 자체도 기록 | 결과 없음 |
| 마켓 인사이트 — 모든 역할 | 이용 고지 → 기관·발행일·언어 → 제목(원문) → 요약 | 기관 칩 + 제목 검색, 12건씩 "더 보기"(카드형 열람에 페이지 크기 선택 불필요) | — | 결과 없음, 마지막 자료 표시 |
